## 📋 Descripción

Portfolio profesional desarrollado con **Next.js 16** y **React 19**, diseñado para mostrar mi experiencia como **Desarrollador Full-Stack** y **Arquitecto de Software**. El sitio presenta un diseño moderno y responsivo con animaciones fluidas, secciones organizadas y una experiencia de usuario optimizada.

### 🎯 Objetivo

Presentar de manera profesional mi trayectoria, habilidades técnicas, proyectos destacados y experiencia en el desarrollo de soluciones tecnológicas para empresas de diversos sectores.
